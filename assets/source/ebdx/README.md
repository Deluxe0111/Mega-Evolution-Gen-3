# EBDX source art staging area

Run `1_IMPORT_EBDX_ASSETS.bat` from the repository root, or copy your existing `EBDX_Mega_Assets` folder contents **into this directory**.

Keep source PNG strips exactly as downloaded. Do not rename EBDX filenames until they have been mapped to the generated `mega_roster.csv`.
